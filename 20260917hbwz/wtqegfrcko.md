# 宫颈癌疫苗这个月到湖南，你想知道的都在这里……

> 更新时间：2026-09-17 (UTC+8)

千呼万唤，

**宫颈癌疫苗终于正式在内地上市，**

疫苗不断更新换代，

二价、四价、九价，

数字背后代表什么？

**到底打还是不打，**

**你想明白了吗？**

我们特别盘点大家最关心的问题，

邀请专家在这里为大家答疑解惑

**1.**** ****前段时间，宫颈癌疫苗上市的消息火遍朋友圈，湖南预计9月到货可以接种，这是一种什么疫苗呢？**

HPV病毒，即乳头瘤病毒，是一种最常见的性传播疾病的病原体，常引起生殖器湿疣，宫颈上皮内瘤变，某些HPV病毒持续感染还会引起宫颈癌。**宫颈癌疫苗，就是针对导致宫颈癌的高危HPV病毒亚型研发的预防性疫苗。**

医学界研究表明，**99.7%的子宫颈癌都是由于HPV病毒导致的。**国际上普遍认定，**HPV疫苗对9-45岁的女性都有预防效果，如果女性能在首次性行为之前注射HPV疫苗，会降低90%的宫颈癌及癌前病变发生率。**

为什么要去打宫颈癌疫苗，主要还是因为宫颈癌的高发。**宫颈癌是仅次于乳腺癌的女性恶性肿瘤，在中国每年约有13万新发病例，占全世界宫颈癌新发病例总数的28%**。

全球平均每1分钟即查出1例新发病例，每2分钟有1名女性死于宫颈癌。每100万HPV感染者中，有10万会发生子宫颈细胞学异常，其中8000人发展为高度病变，1600人最后发展为子宫颈癌。也就是说，HPV感染者发展为子宫颈癌的几率是0.2%。

**2. ****四价疫苗已获批准，有望年底上市，二价和四价有什么区别？价是什么意思？**

价代表的是HPV病毒的亚型，16和18是高危型HPV病毒，6和11是低危型病毒。目前有三种HPV疫苗上市，分别是默沙东的四价（6、11、16、18型）、九价（6、11、16、18、31、33、45、52、58）HPV疫苗和葛兰素史克公司的二价（16、18型）HPV疫苗。

**药监局已经批准的二价疫苗接种年龄为9-25岁，四价疫苗接种年龄为20-45岁，两种疫苗接种年龄不同。**其实在国外，四价疫苗也可以应用于9-25岁的人群，四价疫苗的接种年龄范围更大。

从效率来讲，全球3.1亿人次，无论是二价疫苗还是四价疫苗的接种效果都很不错。在全球宫颈癌发病人群中，70%以上HPV16/18阳性，中国宫颈癌流行病学显示，HPV16/18阳性占宫颈癌的80%以上。

**二价疫苗主要针对HPV16/18，四价疫苗除了可以预防HPV16/18，还在二价疫苗的基础上加了针对HPV6/11的预防****，而90%的尖锐湿疣是由这两种HPV亚型引起的。**九价疫苗是在四价疫苗的基础上，再覆盖了31/33/45/52/58（其中HPV52/58型是亚洲人最易感染的），能预防90%的宫颈癌的发生。

**3. **** 除了年龄的限制外，二价宫颈癌疫苗有其他限制条件吗？比如哪些人不能打？**

其实，**年龄的限制并不是绝对的，关键是看有没有性生活，HPV疫苗对于无性生活的女性效果最佳。**而如果有人打算一辈子都不过性生活，那么注射疫苗的必要性也就非常小了。

有过性生活以后就不能接种 HPV疫苗了吗？也不是，基本上随时都可以接种，只是性生活一旦开始，感染HPV的机会大大增加，**如果曾经感染过了HPV，那么接种疫苗的意义相对不大。**

官方机构从药物经济学角度来考虑，**年龄小的时候接种疫苗，获益时间更长；**年龄越大，花费相同的钱，获益时间明显缩短，不划算。宫颈癌是可以筛查的。按照宫颈癌的筛查策略，在癌前病变时就发现问题，然后尽早解决，可以阻止向宫颈癌发展。

**孕妇、急性感染、免疫缺陷者不宜接种HPV疫苗。**

**4. ****疫苗要打几次，每次隔多长时间，****价格是多少？能保多少年呢?**

HPV疫苗通常分3次给药注射，共需要6个月左右的时间完成，即开始的第1次、第2个月注射第2次，6个月后注射最后一次。**初步价格580一针，****三针共1740元。**

**关于HPV 疫苗接种后的保护期，美国疾控中心的数据是6年，而且保护效果并不随着时间的推移而减弱。**6年的数据主要是因为该疫苗上市才8年，还需要更长的时间来观察，HPV疫苗是否有更长的保护期甚至终生有效也只有留给时间来回答。

**5. ****接种了宫颈癌疫苗后就可以一劳永逸了吗？**

有人认为“打了疫苗就可以不得宫颈癌”，这应该有误区。国内二价疫苗针对的是两种亚型16和18型，疫苗可以降低这部分亚型引起宫颈癌的发生率。

但导致宫颈癌的HPV还有其他亚型，不在预防范围内（4价、9价也不能完全覆盖）。因此，**即使接种HPV疫苗，也应该按照正规的宫颈癌筛查策略，接受宫颈癌筛查。**

预防宫颈癌有哪几道防线呢？**第一道防线：注射HPV疫苗**，这是子宫颈癌的一级防治措施。**第二道防线：建议21岁以上的女性或者有性生活3年以上的女性，至少每两年做一次宫颈细胞学检查(即TCT)。**

如果发现HPV阳性，可以进一步做阴道镜检查，必要时病理检查，以判断是否有癌前病变。**第三道防线：对中、重度的癌前病变，应该做手术，即宫颈锥切，以判断其是否为更严重的宫颈原位癌、宫颈早期浸润癌、宫颈浸润癌**，以便医生进行合理的治疗。

可以说，如果这样定期做防癌检查，可以及早阻断子宫颈癌发展。

**6. **** 听说四价疫苗男性也可以接种，怎么理解呢？**

**四价和九价HPV疫苗，确实男性可以接种，可以预防肛门癌、阴茎癌和生殖器疣。**但是由于男性相关恶性疾病发病率低，出于成本-获益比考虑，也有人认为性价比不高，必要性不大。

男性如果接种HPV疫苗的话，建议接种九价而不是四价的，因为覆盖面更大。年龄推荐9～12岁，之前没接种过的13～21岁也可以补种。

**接种最佳时机是首次性生活之前**，如果有过性生活，在接种年龄内，也可以打，但获益会减少。

**7.****  注射宫颈癌疫苗会不会有副作用？**

****

因个体差异，注射疫苗之后有些人会出现类似感冒的症状，**如头晕、呕吐、胃胀等症状，最常见的问题是注射部位产生疼痛、发红。**

据疫苗不良事件报告系统统计，超过6000万剂的HPV疫苗已被应用，并没有数据表明疫苗接种后出现任何严重的不良反应。

**相对四价疫苗，九价HPV疫苗的注射部位肿胀、红斑的发生率较高，**且随剂型次数增加其发生率逐渐升高；除此之外，九价疫苗和四价疫苗有同样的安全性。

任一曾经对HPV疫苗的任何成分或前剂疫苗本身发生过威胁生命的过敏反应的患者，都不应该继续接种该疫苗。

妇产科医师或其他医疗机构应该对严重过敏包括酵母过敏的患者进行评估，且对患有中度或重度疾病者应等待疾病好转后再接种疫苗。

**最后，还有几个关于宫颈癌疫苗的关键问题**

1.初次性生活之前注射疫苗，预防效果最好。

2.孕妇、急性感染、免疫缺陷者不宜接种。

3.HPV 疫苗通常分3次给药注射，共需要6个月左右完成，即开始的第1次、第2个月注射第2次，6个月后注射最后一次。

4. 疫苗接种后可能会有轻微副作用，如注射部位出现红疹、肿胀及疼痛，或发生过敏反应。也有极少数出现严重副作用。

5.除了注射疫苗，定期筛查也很重要。我国1/4的宫颈癌患者在发现之前从来没做过筛查，导致错过了早期发现及治疗的机会。
